# 単語リズム PWA

iPhoneのホーム画面に追加して使うことを想定した、個人用英単語帳Webアプリです。

## ファイル
- `index.html`: アプリ本体
- `manifest.webmanifest`: ホーム画面追加時の名前・表示設定
- `service-worker.js`: 一度読み込んだ後のオフライン表示用キャッシュ
- `icon.svg`: アプリアイコン

## iPhoneで使うために
このフォルダをHTTPS対応のWebホスティング先に公開する必要があります。公開後、iPhoneのSafariで公開URLを開き、共有メニューから「ホーム画面に追加」を選びます。

## 保存データについて
単語・学習記録は引き続きブラウザ内の `localStorage` に保存されます。端末間で自動同期される仕組みではありません。ブラウザのデータ消去に備え、アプリ内のバックアップ機能でJSONを書き出してください。

## 注意
このプロジェクトはファイル構成を作成した段階です。公開サーバーへのデプロイや、実機iPhoneでの動作確認はまだ行っていません。
